AI MATHEMATICS WORKSHOP POSTER

Contents
  AI_Maths_Workshop_Poster.tex - editable one-page A4 poster
  CUHK-Shenzhen.jpg - supplied campus photograph
  registration_QR_12_2026.png - supplied registration QR code

Compilation
Keep these three files together in one folder and run:
  pdflatex AI_Maths_Workshop_Poster.tex
  pdflatex AI_Maths_Workshop_Poster.tex

The source uses pdfLaTeX and standard TeX Live / MiKTeX packages.
In Overleaf, upload the folder contents and select pdfLaTeX.

Editing
All text is editable in the .tex file. Positions in the TikZ drawing
are in millimetres from the upper-left corner of an A4 page.
The title, description, event details, registration and organising
committee sections are labelled in the source.

The QR code and its clickable area both open the registration form.
The contact address opens an email draft. No conference website link
or program is included.
